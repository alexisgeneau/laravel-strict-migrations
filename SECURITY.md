# Security

If you find a vulnerability in this package, email **contact@cote-dev.fr** rather than opening a public issue. Include the affected version, the steps to reproduce and, if you have one, a suggested fix. You will get an answer within a few days, and a fix or a mitigation before any public disclosure.

The package runs your own migrations against your own database connections, without letting their statements through during the analysis; it takes no input from requests, files or the network.
